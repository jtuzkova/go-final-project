Веб-сервер, который реализует функциональность планировщика задач — аналог TODO-листа. А также для управления персональными задачами с поддержкой повторяющихся событий. Проект представляет собой REST API с веб-интерфейсом для создания, редактирования, удаления и отслеживания задач с возможностью настройки повторения по правилам.

Основные возможности:

-Создание, просмотр, редактирование и удаление задач
-Автоматический расчет следующей даты выполнения для повторяющихся задач
-Поиск задач по дате и тексту
-Авторизация 
-Отметка задач как выполненных с автоматическим пересчетом даты
-Хранение данных в SQLite

Задачи со звездочкой:

-Реализована возможность определять извне порт при запуске сервера. Если существует переменная окружения TODO_PORT, сервер при старте слушает порт со значением этой переменной. 
-Реализована возможность определять путь к файлу базы данных через переменную окружения. Для этого сервер получает значение переменной окружения TODO_DBFILE и использует его в качестве пути к базе данных, если это не пустая строка.
-Добавлена возможность искать задачи по строке или дате через строку "Поиск".
-Реализована атентификация. Пароль хранится в переменной окружения TODO_PASSWORD. Если это значение не пустое — запрашивается пароль.

Доступ к приложению осуществляется по адресу http://localhost:7540

Запуск проекта локально
1. Клонирование репозитория

git clone <url-репозитория>
cd go-final-project

2. Установка зависимостей
go mod download

3. Настройка окружения
Файл .env в корне проекта:

# Порт для запуска сервера (по умолчанию 7540)
TODO_PORT=7540

# Пароль для доступа к приложению (если не задан, авторизация отключена)
TODO_PASSWORD=1234

# Путь к файлу базы данных (по умолчанию ./scheduler.db)
TODO_DBFILE=./scheduler.db

4. Запуск сервера
go run main.go
